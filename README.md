## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- API keys (Google AI, OpenAI, etc.)

### Installation
```bash
git clone https://github.com/ZOOKA-AI/zooka-ai-cosmos.git
cd zooka-ai-cosmos
npm install
```

### Configuration
Create `.env` file:
```env
API_KEY=your_api_key_here
```

### Usage
```bash
npm start
```
